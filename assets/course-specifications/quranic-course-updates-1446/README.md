# تحديثات مقررات القرآن وعلومه 1446هـ

تضم هذه الحزمة أربعة توصيفات جديدة فقط من أرشيف «توصيفات أخرى». لم تُنسخ الملفات التي كانت موجودة ومكتملة في الموقع، ومنها «أصول التفسير ومناهجه» و«التفسير الموضوعي».

- شرط الربط: تطابق اسم المقرر ورمزه معًا مع خطة القرآن وعلومه الجديدة، إصدار 47.
- مصدر النبذة: تحرير موجز من خانة «الوصف العام للمقرر».
- الاعتماد: مجلس قسم القراءات، الجلسة 13، بتاريخ 1446/10/10هـ.
- الجودة: الملفات A4 وRTL، وجدول الاعتماد كامل في الصفحة الأخيرة، ولا تحمل وسم حساسية.
- ملاحظة: اسم ملف مصدر «أصول التفسير» يوحي بالرمز `2002251`، لكن الرمز المثبت داخل التوصيف هو `20022250-2` وهو المطابق للخطة.

تفاصيل المصدر والبصمات ونتائج المطابقة محفوظة في `manifest.json` و`hashes.sha256`.
