# استرداد توصيفات الملف الجامع في Google Drive

حزمة من خمسة توصيفات مقتطعة بحدود صفحاتها الأصلية من ملف جامعة الطائف الجامع لمقررات قسم القراءات المقدمة للأقسام الأخرى. لم يتغير المحتوى المرئي؛ أضيف فقط نص هوية غير مرئي لتحسين الاستخراج الآلي.

- المصدر الخارجي وبصمته ونطاق كل مقرر موثقة في `manifest.json`.
- بقي ملف المصدر الجامع خارج المستودع ولم يُعدّل.
- رُبطت تسعة مواضع في الخطط بخمس هويات مقررات.
