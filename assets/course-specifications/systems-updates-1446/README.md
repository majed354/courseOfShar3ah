# تحديثات مقررات الأنظمة 1446هـ

تضم هذه الحزمة ثلاثة توصيفات تسد فجوات فعلية، وأربعة بدائل محدثة لتوصيفات كانت منشورة مع تحذير اختلاف الساعات. لم تُعد معالجة المقررات السبعة الأخرى الموجودة والمكتملة.

- الإضافات: إجراءات التنفيذ القضائي، الأوراق التجارية والإفلاس، القانون الإداري.
- البدائل: مصادر الالتزام، القانون التجاري، القضاء الإداري، العقود التجارية وعمليات البنوك.
- شرط الربط: تطابق اسم المقرر ورمزه معًا في خطتي الأنظمة 38 و47.
- مصدر النبذة: تحرير موجز من خانة «الوصف العام للمقرر».
- الاعتماد: قسم الأنظمة، الجلسة 23؛ خمسة ملفات بتاريخ 1446/9/4هـ، و«القانون التجاري» و«العقود التجارية وعمليات البنوك» بتاريخ 1446/9/10هـ.
- الجودة: الملفات A4 وRTL، وجدول الاعتماد كامل في الصفحة الأخيرة، ولا تحمل وسم حساسية.

أُبقي توصيف «الإجراءات الجزائية» المنشور سابقًا لأن النسخة الجديدة تسجل الساعات خطأً على أنها 45، وحُجبت الملفات التي تحمل وسم `Restricted` أو لا تطابق الاسم والرمز معًا.
