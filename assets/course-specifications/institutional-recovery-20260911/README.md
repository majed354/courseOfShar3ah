# استرداد مؤسسي لتوصيفات القرآن وعلومه — 2026-09-11

تضم الحزمة سبعة توصيفات من المكتبة المؤسسية الشاملة. ثلاثة منها تحمل رمز المقرر مطبوعًا، وأربعة كان نقص الرمز فيها محصورًا في خانة الغلاف (خانة فارغة أو عبارة إدارية). اكتملت الهوية من اسم الملف المؤسسي والخطة المطابقة والعنوان والبرنامج والساعات.

لم يتغير المحتوى المرئي لملفات PDF. أضيفت هوية نصية غير مرئية وبيانات وصفية لتحسين الاستخراج الآلي. اقتصرت الروابط على برنامج القرآن وعلومه، وبقيت سياقات القراءات والأنظمة غير مربوطة حتى يظهر دليل خاص بها.
