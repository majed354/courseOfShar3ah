## ضوابط المراجعة والتحقق المصححة

- أي عنوان مظلل بالأخضر ومقترن بعبارة «تم إتاحته مؤخرًا» أو «تم إتاحته في التحديث الأخير» يبقى في التوصيف ولا يعامل مرجعًا مستبعدًا.
- ملاحظة الإتاحة الخاصة بالعنوان مقدمة على قاعدة الاستبعاد العام للمؤلف.
- لا يُعامل مجرد تشابه اسم المؤلف على أنه تطابق؛ روجعت يدويًا الحالات المتشابهة.
- أعيدت ملفات التوصيف التسعة إلى نسخها السابقة المطابقة ببصماتها الأصلية، بدل إجراء ترميم جزئي قد يغير بنيتها.
- احتفظت الملفات السبعة المعدلة نهائيًا بعدد صفحاتها نفسه، واجتازت فحص بنية PDF والمراجعة البصرية لمواضع التعديل.
- التفاصيل الآلية الكاملة، بما فيها البصمات وقائمة التصحيح، محفوظة في `manifest.json` داخل هذا المجلد.
