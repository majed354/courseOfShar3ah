## ضوابط المراجعة والتحقق

- لم يُعامل مجرد تشابه اسم المؤلف على أنه تطابق؛ روجعت يدويًا الحالات المتشابهة مثل الغزالي والطحاوي والتلمساني.
- لم تُحذف جميع مؤلفات مؤلفٍ ورد له عنوان مستبعد، إلا إذا نصت القائمة على استبعاد المؤلف عمومًا.
- احتفظ كل ملف بعدد صفحاته نفسه، واجتاز `qpdf --check`، ورُندر موضع التعديل في كل ملف وراجع بصريًا.
- التفاصيل الآلية الكاملة، بما فيها بصمات الملفات قبل التعديل وبعده، محفوظة في `manifest.json` داخل هذا المجلد.
