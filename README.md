# 📚 خطط ومقررات كلية الشريعة والأنظمة

موقع إلكتروني شامل لعرض الخطط الدراسية والمقررات الأكاديمية لكلية الشريعة والأنظمة بجامعة الطائف.

![جامعة الطائف](https://img.shields.io/badge/جامعة-الطائف-1a4d2e?style=for-the-badge)
![الكلية](https://img.shields.io/badge/كلية-الشريعة%20والأنظمة-c9a227?style=for-the-badge)

## ✨ المميزات

- 🔍 **البحث الشامل**: ابحث عن أي مقرر باسمه أو رمزه
- 📖 **تفاصيل المقرر**: نبذة مختصرة تظهر عند النقر على المقرر
- 📥 **تحميل سريع**: زر مباشر لتنزيل توصيف المقرر بصيغة PDF من نتائج البحث
- 🔁 **حالة المعادلة**: إظهار المعادلات المسجلة، أو التنبيه إلى عدم وجود معادلة مسجلة
- 📋 **عرض الخطط**: عرض كامل للخطط الدراسية مع المستويات
- 🎓 **تعدد البرامج**: بكالوريوس، ماجستير، ودكتوراه
- 📱 **تصميم متجاوب**: يعمل على جميع الأجهزة
- 🌙 **دعم العربية**: واجهة عربية بالكامل مع دعم RTL

## 🗂️ البرامج المتوفرة

### برامج البكالوريوس
- الأنظمة (الخطة 38)
- الشريعة (الخطة 47 - جديدة)
- الدراسات الإسلامية
- القراءات
- القرآن وعلومه

### برامج الدراسات العليا
- ماجستير القراءات
- ماجستير الدراسات القرآنية المعاصرة
- دكتوراه القراءات
- دكتوراه الدراسات القرآنية

## 🚀 التثبيت والتشغيل

### محلياً
```bash
# استنساخ المستودع
git clone https://github.com/[username]/sharia-courses.git

# الدخول للمجلد
cd sharia-courses

# فتح الموقع
open index.html
```

### النشر على Netlify
1. ارفع المستودع على GitHub
2. اربط المستودع بـ Netlify
3. سيتم النشر تلقائياً

## 📁 هيكل الملفات

```
/
├── index.html      # الصفحة الرئيسية
├── data.json       # بيانات المقررات (قابل للتعديل)
├── assets/
│   └── course-specifications/ # توصيفات المقررات وملف تدقيق المطابقة
├── netlify.toml    # إعدادات Netlify
└── README.md       # هذا الملف
```

تُحفظ النبذات وروابط ملفات PDF في الحقل العلوي `course_details` داخل `data.json`، مفهرسة بالرمز الكامل للمقرر. وتعرض الواجهة تحذيرًا واضحًا عندما تكون المطابقة بالاسم فقط أو عندما يختلف رمز ملف التوصيف عن رمز الخطة.

## ✏️ تعديل البيانات

لتعديل المقررات أو إضافة برامج جديدة، عدّل ملف `data.json`:

```json
{
  "programs": [
    {
      "id": 1,
      "name": "اسم البرنامج",
      "name_en": "Program Name",
      "degree": "بكالوريوس",
      "version": 47,
      "plan_type": "جديدة",
      "total_hours": 130,
      "courses": [
        {
          "code": "2001105-2",
          "name": "اسم المقرر",
          "name_en": "Course Name",
          "hours": 2,
          "level": 1,
          "type": "نظري"
        }
      ]
    }
  ]
}
```

## 🎨 التخصيص

### تغيير الألوان
في ملف `index.html`، عدّل المتغيرات في `:root`:

```css

    --primary: #1a4d2e;        /* اللون الرئيسي */
    --accent: #c9a227;         /* اللون الثانوي */
    --bg-cream: #faf8f3;       /* لون الخلفية */
}
```
