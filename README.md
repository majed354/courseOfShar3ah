# 📚 خطط ومقررات كلية الشريعة والأنظمة

موقع إلكتروني شامل لعرض الخطط الدراسية والمقررات الأكاديمية لكلية الشريعة والأنظمة بجامعة الطائف.

![جامعة الطائف](https://img.shields.io/badge/جامعة-الطائف-1a4d2e?style=for-the-badge)
![الكلية](https://img.shields.io/badge/كلية-الشريعة%20والأنظمة-c9a227?style=for-the-badge)

## ✨ المميزات

- 🔍 **البحث الشامل**: ابحث عن أي مقرر باسمه أو رمزه
- 📖 **تفاصيل المقرر**: نبذة مختصرة تظهر عند النقر على المقرر
- 📥 **تحميل سريع**: زر مباشر لتنزيل توصيف المقرر بصيغة PDF من نتائج البحث
- 🔁 **حالة المعادلة**: إظهار المعادلات المسجلة، أو التنبيه إلى عدم وجود معادلة مسجلة
- 📋 **عرض الخطط**: عرض كامل للخطط الدراسية مع المستويات
- 🎓 **تعدد البرامج**: بكالوريوس، ماجستير، ودكتوراه
- 📱 **تصميم متجاوب**: يعمل على جميع الأجهزة
- 🌙 **دعم العربية**: واجهة عربية بالكامل مع دعم RTL

## 📁 هيكل الملفات

```
/
├── index.html      # الصفحة الرئيسية
├── data.json       # بيانات المقررات (قابل للتعديل)
├── assets/
│   └── course-specifications/
│       ├── quran-old-v39/     # 38 توصيفًا مقطوعًا للخطة القديمة مع manifest تدقيقي
│       ├── islamic-studies-bundle-1444/ # 58 توصيفًا مقطوعًا للدراسات الإسلامية مع manifest تدقيقي
│       └── ...                # توصيفات المتطلبات العامة
├── netlify.toml    # إعدادات Netlify
└── README.md       # هذا الملف
```

تُحفظ النبذات وروابط ملفات PDF في الحقل العلوي `course_details` داخل `data.json`، مفهرسة بالرمز الكامل للمقرر. وتدعم البنية `variants` و`scopes` لتقييد التوصيف ببرنامج وخطة وإصدار محدد. من حزمة خطة القرآن وعلومه (39)، رُبط 37 توصيفًا بالقديمة، وأعيد استخدام 25 منها في الخطة الجديدة (47) بعد تطابق الرمز والاسم معًا. بقي 12 توصيفًا محصورًا في القديمة لعدم وجود الرمز نفسه في الجديدة، وحُفظ ملف `2002313-2` في الحزمة دون ربطه بأي خطة لاختلاف الاسم. وتعرض الواجهة تحذيرًا واضحًا عند تعارض الساعات.

تضم حزمة الدراسات الإسلامية 58 ملفًا مقطوعًا. رُبط 40 توصيفًا فقط بعد مطابقة الاسم والرمز معًا: 12 في الإصدارين 39 و47، و21 في الإصدار 39 فقط، و7 في الإصدار 47 فقط. حُفظت الملفات الـ18 الأخرى مع نتائج المطابقة في `manifest.json` من دون ربط تلقائي بمقرر، لأن تطابق الاسم وحده أو الرمز وحده لا يكفي.

## ✏️ تعديل البيانات

لتعديل المقررات أو إضافة برامج جديدة، عدّل ملف `data.json`:

```json
{
  "programs": [
    {
      "id": 1,
      "name": "اسم البرنامج",
      "name_en": "Program Name",
      "degree": "بكالوريوس",
      "version": 47,
      "plan_type": "جديدة",
      "total_hours": 130,
      "courses": [
        {
          "code": "2001105-2",
          "name": "اسم المقرر",
          "name_en": "Course Name",
          "hours": 2,
          "level": 1,
          "type": "نظري"
        }
      ]
    }
  ]
}
```
